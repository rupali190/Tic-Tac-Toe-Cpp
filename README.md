# 🎮 Interactive C++ Tic-Tac-Toe (CLI Game)

A clean, terminal-based implementation of the classic **Tic-Tac-Toe** game written in standard C++. Built to demonstrate core C++ fundamentals, 2D matrix manipulation, and structured turn-swapping state logic.


## 🌟 Features

* **2D Array Board Logic:** Efficient 3x3 matrix board rendering and manipulation.
* **Smart Win Engine:** Checks all rows, columns, and diagonal win vectors instantly.
* **Input Validation & Safety:** Prevents cell overwrites, out-of-bounds input, and invalid entries.
* **Frame Redrawing:** Employs dynamic screen clears (`system("cls")`) for a seamless console gameplay UI.

## 🛠️ Concepts & Tech Stack

* **Language:** C++
* **Core Concepts:** 2D Arrays, Functions, Pass-by-Reference, Switch Statements, Game Loops
